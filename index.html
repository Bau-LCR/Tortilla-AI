Términos y Condiciones de Uso

Al utilizar Cut-real AI, aceptás los siguientes términos:

1. Privacidad y datos

Todos los mensajes enviados y recibidos en esta plataforma podrían ser utilizados y revisados por los administradores de Cut-real AI. No envíes información sensible, personal o confidencial.

2. Responsabilidad

Cut-real AI es una herramienta de inteligencia artificial. No nos hacemos responsables por las acciones que realices basándote en la información proporcionada por la IA.

3. Uso adecuado

Te comprometés a usar la plataforma de manera ética y legal. Queda prohibido el uso para actividades ilícitas, dañinas o que violen derechos de terceros.

4. Modificaciones

Los administradores se reservan el derecho de modificar estos términos en cualquier momento.

5. Menores de edad

Si sos menor de 13 años, necesitás el consentimiento de un adulto responsable para usar esta plataforma.

📋 ¿Cómo agregar más API Keys?

  1. Entrá a console.groq.com/keys y creá tantas API Keys como necesites.
  2. En Vercel, andá a tu proyecto → Settings → Environment Variables.
  3. Agregá las siguientes variables con cada key respectiva:
GROQ_API_KEY→ Tu primera API Key (ya existente)
GROQ_API_KEY_2→ Segunda key
GROQ_API_KEY_3→ Tercera key
GROQ_API_KEY_4→ Cuarta key
GROQ_API_KEY_5→ Quinta key
GROQ_API_KEY_6, _7, _8...→ El sistema las detecta solas, sin límite

⚡ El servidor rota automáticamente cuando una key recibe un error 429 (rate limit). Con 5 keys de 10.000 tokens cada una = 50.000 tokens antes del bloqueo total.
